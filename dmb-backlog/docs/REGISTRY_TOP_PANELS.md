# Верхние панели пяти реестров

Проверено по реализации и в Windows Chromium: 11.11.2026.

Единый эталон — Бэклог. Утверждённые [референсы](../artifacts/registry-panel-references-2026-11-11/index.html) сохранены без перегенерации.
Реализация использует именованную композицию UI Kit `ui-registry-reference`,
модуль `frontend/js/ui/registryPanel.js` и изолированный stylesheet
`frontend/css/ui/registry-panel.css`. Бэклог не подключает эту композицию.

## Состав страниц

| Страница | Порядок верхних блоков |
|---|---|
| Метрики | Заголовок → период → создание и колонки; поиск и действия; команда, владелец, проект, состояние, область; быстрые условия; реестр |
| Проекты | Заголовок и переключатель таблица/карточки; поиск и действия; команда задач бэклога, ответственный PL; количество; реестр |
| Рабочие задачи | Заголовок; создание, вид, обновление; очереди; поиск и действия; статус, приоритет, исполнитель, проект; быстрые условия и сортировка; реестр |
| Запросы заказчиков | Заголовок; вкладки запросов/редакций БТ; поиск и действия; режим, стадия, команда, заказчик, координатор; быстрые условия и сортировка; список |
| Мои запросы | Заголовок; создание/продолжение черновика, обновление; поиск, сортировка, сброс; подборки; пояснение и список |

Desktop использует small-контролы UI Kit (28 px), общую подложку,
скругление 10 px, отступы панели 8×12 px и межэлементный интервал 8 px.
На mobile сохраняются touch targets; заголовок и действия занимают разные
строки, поля — две колонки, очереди доступны через select, быстрые условия
раскрываются кнопкой. Поиск и переключатель вида рабочих задач остаются видимыми.

Исходные поля фильтров перемещаются между закреплённой строкой и «Все фильтры»;
они не клонируются. ID, обработчики, значения, URL, права и API сохраняются.
В Проектах изменение закреплённого поля отправляет исходную форму.
Открытие инспектора рабочей задачи по-прежнему сворачивает условия;
кнопка «Показать фильтры» раскрывает их обратно.

## Проверка и свидетельства

Результаты: основной функциональный прогон — 105 PASS и 20 несовпадений
устаревших ожиданий; после исправления ожиданий все затронутые сценарии прошли
повторно (23 PASS, затем 5 PASS). Новые проверки панелей — 17 PASS.
Дизайн-пилот — 11 PASS в режиме полного захвата и 11 PASS в итоговом
screenshot-прогоне без обновления эталонов.

- [Полные fixture-снимки реализации](../artifacts/registry-panel-references-2026-11-11/implementation-after/index.html): пять страниц и контрольный Бэклог, 1440 px обе темы и 390 px.
- [Живые снимки и геометрия](../artifacts/registry-panel-references-2026-11-11/live-after/checks.json): все шесть страниц, те же темы и размеры; горизонтального overflow нет. Вход штатными профилями `po-a`, `ba-a`, `customer-a`; записи БД не изменялись.
- `registryReferencePanels.spec.mjs`: полные экраны, поиск, открытие/закрытие фильтров, мобильные быстрые условия, переключение очереди, возврат в Бэклог.
- `metricsQuarterly.spec.mjs`: сравнение размеров с Бэклогом, период, поиск, сброс, фильтры, колонки, карточки и операции метрик.
- `workDesignPilot.spec.mjs`: список, поиск, отмена фильтров, сортировка/обновление, инспектор и редактор. Старая проверка одной строки поиска/статуса заменена проверкой двух строк, как в референсе.
- Регрессия Бэклога: scope placement, quick edit, freshness; снимки до/после переходов в новые панели. Допуск Windows — 80 пикселей, как в дизайн-пилоте; наблюдаемое отличие 17–40 пикселей сглаживания значков, без изменения геометрии или содержимого. Эталоны Бэклога не обновлялись.

Эталоны рабочих задач обновлены после осмотра полных экранов: поменялись
верхние действия, две строки фильтров и положение списка; на mobile добавлены
видимый поиск, вид, очередь и disclosure быстрых условий. Снимки открытой
карточки отражают новое окружение; скрытие фильтров при инспекторе сохранено.
В тестах запросов исправлены устаревшие ожидания: размер закрытия проверяется
по актуальным токенам UI Kit, `#/settings` ведёт в «Мои уведомления».

## Визуальная оценка и UI Kit

Композиция, порядок действий, плотность и подложки соответствуют референсам.
Иконки, кнопки, segmented control, поля и чипсы используют действующий UI Kit.
Права могут скрывать создание метрики; реальные счётчики, содержимое списков,
названия доступных значений и предметная сортировка не подменены демонстрационными.
Проверка live — чтение страниц; сохранения и отрицательные состояния проверены
изолированными API-fixtures, а не изменением защищённых данных.

Локальный проект: `http://127.0.0.1:8000`; API: `/docs`; журналы: `.runtime/`.
