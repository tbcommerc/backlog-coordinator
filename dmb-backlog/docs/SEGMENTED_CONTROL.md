# Сегментированный переключатель UI Kit

Проверено по коду: 04.11.2026. Вариант А выбран пользователем 04.11.2026.
Общий визуальный контракт: нейтральная подложка и одна подвижная выбранная
поверхность. Принцип взят из SegmentControl IBP, токены и размеры — из UI Kit
Backlog Coordinator. Это компонент режима Operate для существующих композиций
«реестр», «карточка» и «реестр с инспектором».

## Реализация и API

- [segmented.js](../frontend/js/ui/segmented.js) — генератор и жизненный цикл.
- [segmented.css](../frontend/css/ui/segmented.css) — единственный владелец вида.
- [Каталог](../frontend/ui-catalog/segmented.html) — реальные компоненты, состояния
  и размеры; [браузерная регрессия](../frontend/e2e/segmentedControl.spec.mjs).
- `segmentedControl` экспортируется также через `specialized.js` и `ui/index.js`.

```js
segmentedControl({
  label: 'Область бэклога', size: 'small', value: 'team',
  items: [
    { value: 'team', label: 'Команда', attrs: { 'data-scope': 'team' } },
    { value: 'all', label: 'Трайб', attrs: { 'data-scope': 'all' } },
  ],
});
```

Поддерживаются `size`: `extra-small`, `small`, `default`, `large`; `attrs` корня,
`className`, `disabled` всего контрола. У пункта: `value`, `label`, `icon`,
доверенный `iconMarkup`, `iconOnly`, `count`, `disabled`, `attrs`, `className`.
Вариант `ui-segmented-fill` заполняет доступную ширину равными сегментами;
`ui-segmented-compact` — компактная равная ширина коротких областей бэклога.
По умолчанию ширина по содержимому, без пустого хвоста подложки.

## Поведение и доступность

Группа кнопок с доступным именем и `aria-pressed`, всегда один выбранный пункт.
Один вход по Tab; Left/Right, Home/End выбирают доступный пункт через его штатный
обработчик. Недоступные пункты пропускаются, целиком disabled-группа не реагирует.
Enter/Space работают как у обычной кнопки. У иконок обязательны имя и подсказка.

Выбор контролирует экран: после принятого действия обновляет `aria-pressed`.
Компонент не меняет бизнес-состояние оптимистично: отказ от выхода из редактора
и ошибка запроса не переводят индикатор на другое значение. Нельзя выбирать
несколько пунктов или снимать единственный выбор повторным нажатием.

`installSegmentedControls()` один раз устанавливается на стабильный SPA-хост
в `app.js`. Обрабатывает lazy-страницы, новые диалоги, изменение выбранного
пункта, размеров, загрузку шрифтов и скрытие/показ. Возвращает disposer; удалённые
группы освобождаются. Изолированный стенд вызывает установку самостоятельно.
Статическое selected-состояние читаемо и до установки runtime.

Высота всего контрола, включая внутренние отступы: 24/28/32/40px по размеру
и текущим токенам. Сенсорная цель использует общий `control-target-min` (44px).
Страница владеет размещением и внешними отступами; не переопределяет заливку,
рамку, высоту сегментов или активное состояние. Локальные правила прежних
переключателей удаляются, а не перекрываются повышенной специфичностью.
Есть focus-visible, reduced-motion и forced-colors. Длинные варианты не сжимают
уменьшением шрифта: используют короткое ясное имя с полным доступным именем либо
существующий адаптивный select. Например, «1 кв.» / aria-label «1 квартал».

## Матрица применения

| Поверхность | Параметр | Реализация |
|---|---|---|
| Бэклог | Команда / Трайб | `backlogPage.js` |
| Общая панель реестров | Таблица / Карточки | `filterToolbar.js` |
| Метрики v2 | За квартал / За год; квартал карточки | `metricsQuarterly.js` |
| Метрики v1, совместимость | Все / Мои | `metrics.js` |
| Рабочие задачи | Список / Доска / Сводка | `workTasks.js` |
| Активность рабочей задачи | Всё / Комментарии / Изменения | `workTaskDrawer.js` |
| Встречи | Карточки / Хронология | `reports.js` |
| Экспресс-оценка | Утилизация / Баланс | `expressEstimate.js` |
| Квартальное обновление | Месяц старта | `quarterlyGoalsUpdate.js` |
| Персональные настройки | Тема; плотность | `settings.js` |

Выбор месяца по-прежнему сохраняет обычную рабочую запись штатным обработчиком.
Компонент не изменяет справочник сдвигов, права или защищённые данные.
В мобильных рабочих задачах сохранён существующий select представления.
В реестре метрик v2 область «Все / Мои» остаётся select в дополнительных фильтрах:
одиночный выбор в форме не требует замены каждого select на сегменты.

## Семантические исключения

| Семейство | Причина сохранить отдельный компонент |
|---|---|
| Разделы проекта/карточки/настроек, текущий/предыдущий статус, панели и сеансы чата | Навигационные вкладки с tabpanel, а не значение параметра |
| Подборки, сигналы внимания, готовность оценки, полнота контекста, недельные фильтры и уведомления | Фильтрация; чипсы и счётчики сохраняют свой контракт, часть групп допускает несколько условий |
| Архив, группировка, показать пароль, подписки, внимание лидера | Независимое вкл/выкл, checkbox/switch/toggle |
| Палитра акцента и цвет события | Образцы цвета, отдельная доступная палитра |
| Решение по запросу и конфликт версий | Radio-выбор с последствиями/сравнением значений |
| Импорт/экспорт и обычные действия | Кнопки действий, а не выбор режима |
