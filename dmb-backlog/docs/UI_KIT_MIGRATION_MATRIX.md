# Матрица миграции UI kit

Проверено: **2026-10-26**. Статус: **исторический снимок охвата; актуальность проверяется отдельно**.

Источник инвентаря: [migration-matrix.json](../frontend/ui-catalog/migration-matrix.json). Документ генерируется командой `node frontend/ui-catalog/render-migration-matrix.mjs` из каталога `dmb-backlog`.

Матрица фиксирует 117 активных поверхностей. browser-verified означает проверку реального потребителя в перечисленных сценариях, а не наличие CSS-класса. Общие состояния компонентов дополнительно проверяются каталогом; темы, плотность, mobile и coarse pointer — вычисленными размерами, источник геометрии и запрет обходов — по коду. Список states перечисляет применимые состояния: полный перебор всех сочетаний бизнес-данных не заявляется. Предметные расчёты, таблицы и ограничения не заменяются UI kit; адресные исключения и неактивные поверхности перечислены ниже. Подключение общих классов не означает полного визуального соответствия всех сочетаний состояний. Проверка согласованности 17.10.2026 сравнивает вычисленные стили повторяющихся компонентов на 22 поверхностях; оформление таблиц принадлежит UI Kit, предметная геометрия — страницам. Дополнение 19.10.2026: размещение и подтверждение результата выделены из helper-модуля в самостоятельные поверхности. Сложные диалоги дополнительно проверены на 320×568. Изолированные проверки 19.10 не заменяют живой QA-проход 18.10. Дополнение 22.10.2026: унификация реестров проверена отдельно; подробности в docs/dev-testing/VISUAL_REFRESH_2026-10-22.md. 26.10.2026: редактор отчётов удалён из админки по решению пользователя.

Каждая строка содержит прямые браузерные проверки и их область. Предметная компоновка допустима при соблюдении контрактов общих контролов. Проверки исходников: [uiSizingOwnership](../frontend/tests/uiSizingOwnership.test.mjs) и [uiMigrationMatrix](../frontend/tests/uiMigrationMatrix.test.mjs).

Статусы строк отражают исторические сценарии. Текущее подтверждение требует verification-receipt.json с совпадающим SHA-256; проверка npm run check:ui-evidence.

Table Data/Admin — реестры и отчёты; Editor — числовые редакторы; Prose — таблицы в тексте AI; Matrix сохраняет тепловые ячейки. Компактные рабочие таблицы и синхронные строки ресурсов имеют явные варианты. Заголовки у матриц и редакторов общие.
