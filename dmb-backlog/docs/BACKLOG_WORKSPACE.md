# Единый экран «Бэклог»

## Область рядом с созданием — 09.11.2026

Переключатель «Команда/Трайб» размещён в группе действий непосредственно
слева от «Добавить задачу», а не рядом с заголовком. Используется прежний
SegmentControl UI Kit без изменения оформления; при отсутствии права создания
переключатель остаётся доступен. Композиция страницы — «реестр».
Проверка: `backlogScopePlacement.spec.mjs`, изолированные API, обе темы,
1440/390 px; полные снимки в `artifacts/backlog-scope-placement-verified/`.
Визуально проверено соседство и выравнивание контролов на полных fixture-экранах;
live-приёмка этой правки не проводилась.
Дополнительно 09.11.2026 измерены внешние высоты переключателя и видимых
кнопок группы действий: 28 px при 1440 px и 44 px при 390 px, в обеих темах.
Равенство закреплено в том же браузерном сценарии.

## Закрепление шапки таблицы — 09.11.2026

Табличное представление использует [общий компонент](STICKY_BACKLOG_TABLES.md):
шапка закрепляется под навигацией с непрозрачным зазором 16 px. Панель поиска
и фильтров прокручивается вместе со страницей. Термин «закреплённые фильтры»
ниже означает выбранный пользователем набор полей, а не фиксацию при скролле.
Быстрое редактирование сохраняет свою панель над шапкой. Сортировка, выбор
строк, горизонтальный скролл, ширины колонок и клавиатурный фокус сохраняются.
Проверены живой экран и изолированные сценарии, подробные результаты — по ссылке.

09.11.2026: подпись сортируемого столбца и стрелка больше не перекрываются.
Общий вариант UI Kit резервирует место для стрелки и отступ 8 px; длинная
подпись занимает до двух строк с многоточием и полным названием в подсказке.
Правило одинаково до и после закрепления шапки, включая ручное сужение колонок.

## Закреплённые фильтры и каталог — 09.11.2026

Композиция «реестр»: заголовок и действия → строка поиска → закреплённые
фильтры → быстрые подборки → данные. На desktop закрепления расположены
одним рядом из пяти равных полей под поиском. На мобильном — две колонки,
три строки, минимум 44 px для нажатия, без скрытого горизонтального скролла.

По выбору пользователя сохранены прежние стандартные наборы:

| Область | Пять фильтров по умолчанию |
|---|---|
| Трайб | Статус, Приоритет, Команда, Срок, Проект |
| Команда | Статус, Приоритет, Срок, Исполнитель, Тип задачи |

Меню «Все фильтры» позволяет закреплять/откреплять поля булавкой (до пяти).
Ранее сохранённый персональный набор, в том числе пустой, имеет приоритет
над стандартным. Настройки хранятся по пользователю и области в существующем
`dmb_backlog_workspace_v2`; после перезагрузки набор восстанавливается.
Для замены при заполненном лимите нужно сначала открепить одно поле.
«Вернуть 5 по умолчанию» восстанавливает только закрепления и не очищает
выбранные условия, поиск и настройки колонок.

Каталог использует компактные строки без вложенных рамок: название,
текущее значение, раскрытие и отдельное закрепление. Заголовок, поиск,
счётчик и нижние действия доступны при прокрутке. Поиск без совпадений
объясняет отсутствие результатов. В области «Команда» её название показано
отдельным пояснением, без ложного редактируемого поля. Выбор значений,
применение/отмена черновика и активные условия используют прежнюю логику.

Функциональность: Windows Chromium fixture-сценарии
`backlogFilterDesign.spec.mjs`, `unifiedBacklogFilters.spec.mjs` и
`unifiedBacklogCompact.spec.mjs` (без исторического baseline comparison).
Проверяются сохранение и независимость наборов, стандартные пять полей,
лимит, отдельный сброс, поиск, пустое состояние, Escape/возврат фокуса,
длинные значения, обе темы и адаптивность. Итог: 33 PASS (15 новых сценариев
и 18 существующих), без обновления screenshot-эталонов. Модульные контракты фильтров,
предпочтений, маршрутов и responsive layout: 26 PASS.

Визуальная оценка: полные экраны до/после, desktop 1440×900 / 1366×768,
mobile 320/390×844, короткий 1280×400; дополнительно настоящий Chromium
tab zoom 200%. После независимого ревью исправлены избыточная высота
мобильного ряда и схлопывание каталога на коротком экране. Повторный независимый
проход признал оба замечания устранёнными на уровне code + fixture;
мобильная панель стала ниже примерно на 114 px, первая задача видна около y664.
Локальные доказательства: `artifacts/backlog-filters-2026-11-08/`, префиксы
`fixture-before` / `fixture-after`; эти файлы не являются снимками рабочей БД.

UI Kit: именованные варианты `ui-filter-toolbar-stacked`, `ui-pinned-filters`
и `ui-filter-catalog`, общие токены, кнопки и `createPopover`.
[Контракты вариантов](UI_KIT_CONTRACTS.md#каталог-и-закреплённые-фильтры--09112026)
и раздел каталога дополнены; механический детектор Impeccable — без находок.

Live-граница: исходный экран просмотрен 08.11.2026 в действующей сессии.
Повторная live-приёмка 09.11.2026 не завершена: приложение на порту 8000
не запущено. Штатный полный запуск остановился на prerequisite

## Маршруты и доступ

Канонический маршрут — `#/backlog?bv=2&scope=all|team`. Старый
`#/team-backlog` заменяется в истории на `scope=team`, сохраняя task/tab/comment.
Старый bare `#/backlog` сохраняет смысл общей области при наличии DMB-чтения;
для пользователя только командного раздела открывается его команда.
Меню передаёт bv=2, явную область и сохранённые условия вкладки/default-view. Его адрес синхронизируется с последним состоянием без перезагрузки оболочки.
Ошибочная/недоступная явная область не расширяется до all.

Контекст страницы не выдаёт права записи. Строки, quick edit, выбор и карточка
используют `taskCardPermissions.js`; сервер сохраняет окончательную проверку.
Неизвестное явно заданное task-action право запрещает действие. Legacy fallback
работает только при отсутствии явно заданного значения. Права comment/delete
проверяются независимо. Названия полей админки обновлены, ключи разрешений прежние.
Metric-записи и модель WorkTask не объединены с Task.

URL содержит поиск, фильтры, вид, сортировку и страницу. `bv=2` делает пустые
условия явными. Поиск заменяет текущую запись history; остальные изменения
создают осмысленный переход. Back/Forward восстанавливает состояние.
`return_to` принимается только для безопасного внутреннего маршрута бэклога.
Копирование ссылки карточки сохраняет контекст списка.

## Настройки и перенос

`dmb_backlog_workspace_v2:<userId>` хранит schemaVersion=2, ревизию, lastScope,
отдельные all/team с колонками, закреплёнными фильтрами и saved views.
`dmb_backlog_session_v2:<userId>` в sessionStorage содержит состояние вкладки.
Командное состояние привязано к team_id; при смене команды старое не применяется.
Явный URL имеет приоритет над сеансом и default-view. Выделение не сохраняется.

Web Locks сериализуют изменения между вкладками. Изменение одного view из двух
вкладок предлагает перечитать редакцию либо сохранить копию. Отсутствие блокировок,
ошибка storage и неподдерживаемая/повреждённая схема дают предупреждение и режим
памяти; исходный документ не перезаписывается. Частичные персональные колонки дополняют shared-настройки (financial/effort), а не отменяют их.

04.11.2026 по прямому решению пользователя баннер переноса полностью удалён.
Наличие прежних ключей не показывает предложение и не запускает перенос.
Ручное действие «Перенести прежние настройки» остаётся в меню «Операции».
Шесть legacy-ключей импортируются только после подтверждения принадлежности.
Общий marker `dmb_backlog_legacy_claim_v2` связывает перенос с пользователем.
Повторный импорт не дублирует views; ID двух прежних каталогов разделены.
Повреждённые блоки не мешают остальным. Персональные v2-колонки сохраняются;
конфликтующие legacy-колонки становятся отдельным представлением.
Исходные legacy-ключи не изменяются и доступны старой сборке при откате.

## Данные и действия

`backlogTaskLoader.js` загружает полный снимок страницами по 1000, не более двух
запросов одновременно. Team-запросы содержат team_id текущего пользователя.
Частичный ответ не выдаётся за полный; дубли ID устраняются, нестабильный total
перечитывается один раз. Смена маршрута/поколения/пользователя отменяет старую очередь.

Фильтрация, сортировка, поиск и пагинация по 100 строк работают по полному снимку.
Все 41 baseline-колонка сохранены. Значения внутри фильтра объединяются ИЛИ,
разные поля и восемь быстрых флагов — И. Счётчики флагов относятся ко всей области
до пользовательского отбора; «Найдено» — к итоговой выдаче. До загрузки число неизвестно.
В team команда фиксирована; в all командный фильтр множественный.

Quick edit сохраняет только изменённые поля с версией. Обработчики переходов
сохраняют штатный guard сохранения/отмены/продолжения. Выбор по заголовку охватывает
весь отфильтрованный редактируемый набор, включая другие страницы.
Bulk, импорт, общая карточка, статусы встреч и квартальные операции используют
существующие компоненты/API. Каждая валидная строка импорта дополнительно проходит
объектную task-policy до persist: чужая команда/явный запрет дают фатальную
ошибку permission_denied по team_id; справочники не создаются. Неопределённый
сетевой результат bulk помечается как неподтверждённый, автоматически не повторяется
и блокирует экспорт до успешного обновления списка. Создание из team передаёт свою команду.
CSV экспортирует сохранённую полную отфильтрованную выдачу в порядке видимых колонок,
с BOM/CRLF, экранированием и защитой формул; имя содержит область и дату.
При неполной/устаревшей загрузке экспорт блокируется.

Обновление при dirty, выборе, карточке или форме откладывается. После освобождения
интерфейса выполняется один отложенный refresh. Ошибка обновления оставляет прежний
полный снимок той же области, предупреждение и повтор; актуальность не заявляется.
Уход со страницы снимает обработчики, таймеры, callback и кеш. Карточка уведомляет текущий контроллер после успешного сохранения. Завершение сеанса/отзыв чтения немедленно очищает карточку, черновики и запросы без служебных запросов под новой сессией. Возврат восстанавливает
условия и прокрутку. Доступная карточка вне отбора показывает пояснение, не расширяя список.

## Настройка столбцов — проверено 09.11.2026

Окно «Столбцы» использует UI Kit `ui-popover-columns-editor`: поиск по названию,
счётчик показанных и найденных, один список с независимой прокруткой. Изменения

## Предупреждение актуальности — 09.11.2026

Проверено по реализации 09.11.2026. После неудачного обновления загруженного
списка сохраняются задачи и условия просмотра. Между быстрыми фильтрами и
таблицей/карточками выводится общий `Alert` с `variant: 'inline'`, тоном `warning`,
заголовком «Данные могут быть неактуальны», пояснением «Не удалось обновить
список задач.» и вторичной кнопкой «Обновить». Во время запроса кнопка
заблокирована и подписана «Обновляем…». После успешной загрузки блок скрывается.

При активном редактировании или выделении используется отдельное информационное
состояние «Обновление отложено» без кнопки, обходящей защиту редактирования.
Неподтверждённый результат массовой операции сохраняет отдельное предупреждение.
Первичная ошибка без загруженных задач остаётся состоянием ошибки таблицы.
