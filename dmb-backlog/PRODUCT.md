# Контекст продукта для проектирования

Проверено: 04.11.2026. Справка для Impeccable и других дизайн-инструментов.

Backlog Coordinator — существующее приложение управления бэклогом, проектами и
рабочими задачами. Актуальные возможности и границы описаны в
[AS-IS](docs/PROJECT_OVERVIEW_AS_IS.md), навигация — в [карте проекта](../docs/index.md).

В пилоте пользователь находит задачу в личной или командной очереди, оценивает срок
и состояние, открывает карточку, сверяет ожидаемый и фактический результат,
выполняет разрешённое действие. Реестр нужен для сопоставления записей; карточка —
для работы с одной записью. Эти задачи определяют иерархию, а не количество доступных полей.

Техническая база — существующий JavaScript SPA и его UI Kit. Новый фреймворк,
замена UI Kit и изменение бизнес-правил не входят в дизайн-пилот.
При проверках соблюдать правила защищённых данных из [AGENTS.md](../AGENTS.md).
