# Модули платформы сопровождения сделок

## Сделки (Deal Capture)

- **Назначение:** ввод, подтверждение и валидация сделок.
- **Ключевые функции:** заведение сделки, проверка обязательных полей, привязка продукта и клиента, статусная модель сделки, дубли-контроль.
- **Известные ограничения:** нет автоматической подстановки контрагентов из мастер-данных для новых клиентов; ручной ввод ряда полей при сложных продуктах.

## Расчёты (Settlement)

- **Назначение:** проведение расчётов по сделкам.
- **Ключевые функции:** инструкции на перевод ценных бумаг и денежных средств, контроль даты расчёта (value date), обработка несостоявшихся расчётов (failed settlement), повторный запрос на расчёт (resend settlement instruction).
- **Известные ограничения:** повторный запрос по несостоявшимся сделкам выполняется вручную; нет выделенного экрана со списком проблемных сделок; уведомления о failed trades приходят с задержкой.

## Депозитарный учёт

- **Назначение:** хранение и учёт ценных бумаг, корпоративные действия.
- **Ключевые функции:** позиционный учёт, счета депо, корпоративные действия (дивиденды, погашения), конвертации.
- **Известные ограничения:** часть корпоративных действий обрабатывается вручную.

## Лимиты

- **Назначение:** контроль лимитов на контрагентов, инструменты и портфели.
- **Ключевые функции:** настройка лимитов, проверка перед сделкой, маржинальные требования.
- **Известные ограничения:** нет онлайн-проверки лимитов для ряда ПФИ-операций.

## Отчётность

- **Назначение:** формирование регламентной и операционной отчётности.
- **Ключевые функции:** отчёты по сделкам, позициям, НКД, марже, несостоявшимся расчётам; выгрузки в Excel.
- **Известные ограничения:** отчёты формируются по расписанию; нет дашборда в реальном времени.

## Комплаенс-контроль

- **Назначение:** проверка сделок на соответствие регуляторным и внутренним правилам.
- **Ключевые функции:** pre-trade проверки, AML/KYC, обязательное ревью для структурных продуктов, эскалация нарушений.
- **Известные ограничения:** для части инструментов проверки выполняются пост-фактум.

## Мастер-данные и справочники

- **Назначение:** единые справочники продуктов, контрагентов, валют, инструментов.
- **Ключевые функции:** ведение справочников, версионирование, распространение изменений.
- **Известные ограничения:** часть справочников не синхронизирована с внешними источниками в реальном времени.

## Интеграции

- **Назначение:** обмен данными с внешними системами.
- **Внешние системы:** депозитарий, риск-система, бухгалтерия (A-бэк), платёжная система, CRM, SWIFT, биржевые системы.
- **Ключевые функции:** передача инструкций, получение подтверждений, синхронизация справочников.
- **Известные ограничения:** ряд интеграций работает в полуавтоматическом режиме (подтверждения загружаются вручную).
