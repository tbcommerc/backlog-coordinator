note bottom of Agent
  <b>Граница ответственности</b>
  LLM понимает смысл реплики и предлагает следующий шаг.
  Python валидирует решение, сохраняет состояние, собирает драфт
  и не позволяет модели самостоятельно отправить требование.
end note

note bottom of KBZone
  <b>Ограничение демо-стенда</b>
  База знаний не загружена из подтверждённых корпоративных источников.
  Для production нужны владелец данных, верификация и процесс обновления.
end note
