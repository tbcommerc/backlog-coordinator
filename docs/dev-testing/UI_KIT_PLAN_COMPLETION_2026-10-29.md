# Завершение плана дополнений UI Kit

Дата: 29.10.2026. Реализован согласованный список дополнений после сравнения
с IBP. Это завершение перечисленного плана, не заявление о полном совпадении
возможностей двух дизайн-систем или приёмке всех экранов приложения.

## Матрица результата

| Группа | Реализация и пилот | Отчёт |
|---|---|---|
| ReadOnlyField / DescriptionList | Атрибуты рабочих задач и паспорт метрики | [Карточки](UI_KIT_DETAIL_COMPONENTS_2026-10-29.md) |

Все группы экспортируются через публичный UI API, имеют контракт, пример
в каталоге и браузерные проверки. Используются токены нашего проекта.

## Последняя поставка

StepForm сохраняет DOM полей, проверяет промежуточные шаги, управляет фокусом,
защищает async guard от дублей и поздних ответов, восстанавливает форму при reset.
Контролируемая проекция этапов отделена от пользовательских переходов. В разборе
встреч сохранена прежняя предметная последовательность и API.

SplitPane работает указателем и клавиатурой, ограничивает размер контейнером,
переходит к последовательной раскладке на узком экране, освобождает pointer
capture, ResizeObserver и обработчики при destroy. В рабочем месте сохранены
modal/inline-переходы, пользовательская настройка ширины, черновик и навигация.

При проверке исправлены пропавший пробел в подписи этапа, конфликт прежней
двухколоночной раскладки с разделителем и разная точность разделителя/ползунка.
В тесте обязательного поля исправлен селектор: используется доступное имя
textbox, без декоративной звёздочки label.

## Проверки

- Совместная браузерная регрессия: **150/150 PASS** (12,5 минуты).
  Включает новые компоненты, предыдущие дополнения, метрики, диалоги,
  разбор встреч и рабочее место задач.
- Все frontend Node-тесты: **461/461 PASS**. При первом прогоне обнаружена
  устаревшая генерируемая матрица миграции; после её обновления полный
  повторный прогон прошёл без ошибок.
- Инвентаризации семейств и потребителей: обе проверки `--check` проходят.
  Структурная проверка `check-review-coverage.mjs` проходит. Устаревшие
  доказательства сохранены как история; изменившиеся потребители и маршруты
  требуют отдельного ревью и не отмечены принятыми автоматически.
- Проверены локальные Markdown-ссылки семи связанных документов и
  `git diff --check`. Просмотрены снимки новой формы в светлой настольной
  и тёмной мобильной теме, а также списка с карточкой задачи на 1440 px.

Повторить: `npm run test:ui-completion` из `dmb-backlog/`. Собственный статический
сервер 4191, все операции API подменены фикстурами. Реальные защищённые данные
не создавались и не изменялись. Артефакты текущего прогона —
`dmb-backlog/.runtime-ui-plan-completion/`, не для Git.

## Границы завершения

В этом плане нет незавершённых групп компонентов. Пилоты не означают массовую
миграцию всех аналогичных мест приложения. Возможности следующего уровня —
виртуализация/настройка колонок таблиц, множественный EntityPicker, пресеты
интервалов — не входили в реализованную базовую поставку.

Совместная fixture-регрессия не заменяет живую матрицу ролей всего приложения
и полный `verify:ui-kit`. Состояние общего реестра ревью фиксируется отдельно;
старые доказательства не превращаются автоматически в актуальную приёмку.
