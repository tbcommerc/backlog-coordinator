Решение по прогону: `PASS` / `PASS WITH ISSUES` / `FAIL` / `BLOCKED`.

Полнота аудита (отдельно от качества продукта): `ЗАВЕРШЁН` / `В РАБОТЕ` / `ОЖИДАЕТ ДЕЙСТВИЯ ЗАКАЗЧИКА` / `ПРИОСТАНОВЛЕН ЗАКАЗЧИКОМ` / `ТЕХНИЧЕСКИ ПРЕРВАН`.

Перед статусом «ЗАВЕРШЁН» сверить все ID и новые ветви: PARTIAL = BLOCKED = NOT RUN = 0, для PASS/FAIL есть доказательства, для N/A — обоснование. Наличие открытой очереди требует продолжения и следующего конкретного запроса, а не итогового заявления о завершении. Подтверждённый FAIL не закрывает заблокированные им последующие шаги.
