# Улучшения интерфейса рабочих задач

Проверено: **21.10.2026**. Реализованы предложения текущего ревью.

## Изменения

1. Быстрые выборки со счётчиками: сегодня, просроченные, препятствия; доступ к своей приёмке. Серверные счётчики охватывают всю выборку с ACL, без ограничения текущей страницей.
2. Сворачиваемые группы по причинам внимания. Число группы явно обозначает задачи на странице.
3. Единый следующий шаг в сводке и карточке. Снятие препятствия — главное действие, когда сервер определяет его следующим шагом; завершение остаётся доступным вторичным действием.
4. Родительская задача перед применением фильтров. На мобильном — полноэкранная панель, закреплённые кнопки, отмена изменений, Escape и удержание Tab-фокуса.
5. Компактная мобильная шапка и счётчики в селекторе подборок. На живой странице при 390 × 844 CSS px первая строка начинается примерно на 231 px.
6. В личном списке скрыто повторение собственного имени исполнителя; приёмщик остаётся видимым.
7. На доске подписан приёмщик, добавлены маркеры этапов и раскрываемая причина препятствия.
8. В создании приёмщик показывается по необходимости; приоритет и чек-лист свёрнуты, контекст размещён в дополнительных параметрах.
9. В сводке выделены три показателя риска, сокращены строки ближайших действий, исключено дублирование равных итогов.

## Проверки

- Backend: work_tests/test_work_focus.py и test_work_presentation.py — **8 PASS**. Проверены московская дата, активные статусы, ACL, сочетания фильтров и счётчики всей выборки. Изолированная тестовая БД не создаёт защищённые справочники, пользователей и команды.
- Браузерные регрессии: workRedesign.spec.mjs, workListDensity.spec.mjs, workSplitWorkspace.spec.mjs — **56 PASS из 57** в общем прогоне. Сбой ожидания загрузки тестового iframe при 1280 px / тёмной теме прошёл отдельным повтором (**1 PASS**).
- После последних CSS-правок: **15 PASS из 16**, один повторный сбой ожидания начальной загрузки при 390 px / тёмной теме. Точечный повтор: **1 PASS** (11 секунд). Интермиттирующие таймауты тестового стенда остаются ограничением проверки; стабильность всего прогона без повторов не заявляется.
- Размеры автоматических проверок: 320, 390, 768, 1024, 1280, 1440, 1920 px; светлая и тёмная темы; эмуляция увеличенного масштаба.
- Живой интерфейс http://127.0.0.1:8000: список, быстрый фильтр «Сегодня» (2 задачи), сохранение фильтра при переходе на доску, мобильные фильтры, карточка с препятствием, раскрытие причины на доске, сводка и условный приёмщик в создании.
- Живая проверка выполнена при эффективных размерах **1440 × 960** и **390 × 844 CSS px**. Горизонтального переполнения документа нет. Это браузерная эмуляция размеров телефона, не испытание на физическом телефоне и не Safari/iOS.
- Во время живой проверки записи не сохранялись и переходы статусов не выполнялись. Использована существующая QA-сессия. Защищённые данные не менялись.
