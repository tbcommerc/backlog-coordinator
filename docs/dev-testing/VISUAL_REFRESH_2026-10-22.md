# Унификация реестров — 22.10.2026

Статус: реализованы изменения V01–V10; приёмка компонентов на тестовых данных.
Живой ролевой прогон и настоящий браузерный zoom 200% этим отчётом не заявляются.
Использованы реальные модули SPA и изолированные API-fixtures; БД не изменялась.

  1440/1280/390/320 × light/dark × 8 состояний: очередь, сводка, drawer,
  создание, уведомления, инструментальная панель DMB, каталог фильтров DMB, UI-каталог.

  полная таблица DMB на 1440/1280/720/390/320 в двух темах. Для полной таблицы
  DMB в этом прогоне есть after, отдельного before нет. `dmbVisual.spec.mjs`
  проверяет DMB через основную оболочку и Router с подменённым API:
  8 PASS, снимки `dmb.png` и `filters.png` в подкаталогах `dmbVisual-*`.
- `visualRefresh.spec.mjs` + `workTaskDrawer.spec.mjs`: 27 PASS, включая

- `uiKitComposites.spec.mjs`: 30 PASS — вложенные панели, полный каталог фильтров,

Снимки — компонентные, с демонстрационными данными. В fixture очереди верхняя
полоса содержит подпись демонстрационного экрана; это не реальный топбар Router.
720 CSS px проверяет доступную ширину, но не имитирует все эффекты настоящего
zoom 200%. Длинные уведомления и mobile допускают рост строки сверх 64 px.
