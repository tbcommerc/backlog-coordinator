# Пилот качества дизайна рабочих задач

Дата: 04.11.2026. Область: реестр, карточка просмотра/редактирования и инспектор.
Статус: внедрённый пилот; проверена изолированная полная оболочка SPA.
Live-приёмка и одобрение визуального результата пользователем остаются открытыми.

## Внедрение

- Установлен [Impeccable](https://github.com/pbakaus/impeccable), версия skill 4.8.0,
  в пользовательский каталог Codex. Применён контекст Operate. Для следующих задач
  добавлены [PRODUCT.md](../../dmb-backlog/PRODUCT.md), [DESIGN.md](../../dmb-backlog/DESIGN.md)
  и правила в [AGENTS.md](../../AGENTS.md).
- Зафиксированы [три композиции](../../dmb-backlog/docs/UI_PAGE_COMPOSITIONS.md)
  на существующем коде: реестр, карточка, реестр с инспектором.
- Добавлены именованные варианты UI Kit: навигационные filter chips, inline-поля,
  панель условий, раздел без вложенной рамки, сводка основных атрибутов.
  Из рабочего CSS удалены соответствующие локальные переопределения.
- Создан [каталог вариантов](../../dmb-backlog/frontend/ui-catalog/page-compositions.html).
- Добавлены 15 эталонных PNG и `npm run test:design`, отдельная Windows-задача CI.
  Неявное обновление эталонов запрещено; допуск сравнения — 80 пикселей.
  CI из чата не запускался; Windows CI может потребовать калибровки шрифтов/среды.

## Проверки и ограничения

**Функциональность.** Новый набор: 10 сценариев, 15 снимков; поиск, пустая выдача,
отмена фильтров, открытие карточки, основные атрибуты, редактор, overflow и варианты
UI Kit. Все API изолированы, защищённые данные и реальные записи не менялись.
Строгая screenshot-регрессия `npm run test:design -- --reporter=line` без обновления
эталонов: **10 PASS, 15 снимков, 35,1 с**. Локальные ссылки новых документов и
`git diff --check` изменённых файлов прошли проверку.

Расширенная целевая E2E-регрессия: 21 PASS, 2 FAIL. Прошли общие карточки, desktop-поиск,
транзакционные фильтры 1440/1024/390/320 px и очередь с модальной карточкой.
Два `workQueueAlignment` на 1440/1920 ожидают `.work-queue-note` с текстом
«Есть препятствие», отсутствующий в текущей разметке. Геометрические проверки до
этого ожидания проходят. Тесты не ослаблялись; полная регрессия не объявляется успешной.

Общая frontend unit-регрессия: 499 PASS, 1 FAIL из 500. Открыт `BU-D16` в
`unifiedBacklogLifecycle.test.mjs`: сравнительный замер загрузчика бэклога не проходит
порог производительности. Загрузчик пилотом не изменялся; повторный прогон сохранил
проблему. Она не скрыта исключением теста.

**Дизайн.** Осмотрены полные fixture-экраны обеих тем, ноутбука и телефона,
редактор и общие варианты. Исправленные участки стали последовательнее — это оценка
агента, не пользовательская приёмка. Все роли, редкие состояния, zoom 200%, forced
colors и полный жизненный цикл сохранения этим пилотом не покрыты.

**UI Kit.** Варианты в общем слое сохраняют токены и семантику компонентов;
проверены компонентами и полными экранами. `impeccable detect --json` для изменённой
разметки вернул `[]`. Это не доказательство отсутствия визуальных проблем и не
полный аудит прежнего CSS. Контракты и профильная документация обновлены.

**Live.** Две попытки подключить управляемый браузер завершились таймаутом.
Изолированные снимки не выданы за live-доказательства. Приложение на 8000 и общая
матрица приёмки остаются непроверенными в этом пилоте.

Автоматическая проверка отклонила добавление выгрузки screenshots/traces в GitHub
artifacts из-за возможного содержимого данных приложения и отсутствия разрешения
на внешнюю передачу. Выгрузка не добавлена; локальная проверка сохранена.

## Следующие страницы

Сначала выбрать композицию и порядок информации, затем использовать действующий
UI Kit, выполнить визуальный цикл и регрессию. Impeccable помогает этому процессу.
Пилот не доказывает преимущество инструмента над альтернативами и не означает,
что остальные страницы уже получили такой же дизайн.
