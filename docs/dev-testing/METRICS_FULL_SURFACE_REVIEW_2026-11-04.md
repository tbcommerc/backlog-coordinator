# Метрики — проверка раскрытых состояний R7

Продолжение [R6](METRICS_IMPECCABLE_REVIEW_2026-11-04.md). Прежний общий вывод
о визуальной готовности не восстанавливается задним числом. Основа проверки:
[DESIGN.md](../../dmb-backlog/DESIGN.md), [UI Kit](../../dmb-backlog/docs/UI_KIT_CONTRACTS.md)
и [протокол ревью](../../dmb-backlog/docs/UI_KIT_REVIEW_PROTOCOL.md).
Режим Impeccable — Operate: существующая дизайн-система, рабочая плотность,
предсказуемые формы. Проверка одним агентом, без заявления о независимой дизайн-приёмке.

| R7-17 | Подтверждения удаления/снятия связи имели безликое «Подтвердить» | Кнопки называют действие, удаление использует общий danger-стиль |
| R7-18 | Раскрытый комментарий дублировал превью и сохранял подпись «Развернуть» | После раскрытия заголовок становится «Свернуть комментарий»; полный текст показан один раз |

Локальные стили метрик отвечают за предметную сетку, таблицы и график.
Размеры, цвета, состояния и внутренние отступы контролов не исправляются
селекторами страницы. Из shared API расширены только безопасный атрибут `form`
для Button и необязательный `name` для SelectionList.

Автоматические проверки используют изолированные ответы API и реальный код
компонентов/CSS. Это не подтверждение сохранения всех операций в живой БД.
Живая проверка R7 выполнена под существующей QA ba-a: создание и раскрытые
настройки, факт, паспорт, годовые настройки, планы и интервальное расписание.
Сохранений в БД в R7 не выполнялось; защищённые записи не изменялись. После обрыва CUA состояние последнего диалога отмены повторно подтвердить не удалось.
Дальнейший живой обход прерывался таймаутами CUA; повторные подключения и новая
вкладка также не отвечали. Эта граница не скрывается за результатами E2E.

## Результаты проверок

- Общая регрессия: 84/85 на промежуточной версии. Единственный оставшийся сбой выявил изменение доступного имени после валидации; исправлен в коде, тест не ослаблялся.
- После исправления: 20/20 (`metrics-r7-verified`): восемь полных композиций, ошибки сохранения, валидация, конфликт, 76 состояний редакторов и переход прежней модели.
- Окончательные раскрытые меню/разделы и снятие связи: 3/3 (`metrics-r7-menus-accepted`). Снимки с иконками: 1440×900 light и 390×844 dark.
- Именованный выбор кварталов, обязательность, фокус ошибки, сохранение `[3,4]`, пустой список встреч, конфликт и создание: 3/3 (`metrics-r7-final-validation`).
- `npm run test:design -- --workers=1 --timeout=60000`: 10/10. Эталоны не перезаписывались.
- Финальная перепроверка раскрытого комментария и всех дополнительных меню: 3/3 (`metrics-r7-comments-final`), обновлены соответствующие снимки.
- Синтаксис обоих JS-модулей, `git diff --check` и 240 локальных Markdown-ссылок проверены; отсутствующих ссылок нет.

Это последовательные прогоны после конкретных исправлений, а не заявление о новом едином полном прогоне. Матрица 19 редакторов снята на 1440×1000 и 390×1000 в обеих темах; двадцатый редактор связи, раскрытые меню и подтверждения — отдельным прогоном на 1440×900 / 390×844. Полные страницы также проверены на 1366×768 и 320×800.

Визуально просмотрены все виды редакторов и сохранённые раскрытые меню, включая длинные данные. Проверка геометрии не заменяла просмотр изображений: именно по снимкам дополнительно исправлены footer и короткие формы. Живая часть имеет указанное выше ограничение CUA; пользовательская приёмка не объявляется завершённой.
