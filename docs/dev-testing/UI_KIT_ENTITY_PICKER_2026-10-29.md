# EntityPicker: поиск и выбор связанной сущности

Дата: 29.10.2026. Третья очередь дополнений UI Kit после сравнения с IBP.

## Реализация

Общий `entityPicker` использует существующие Field/Button и нативный select.
`bindEntityPicker` владеет debounce, AbortSignal, порядком ответов, состояниями
loading/ready/empty/error, повтором, очисткой и освобождением обработчиков.
Выбранная запись видна полностью под полем; длинный текст переносится.
Ноль допустим как ключ сущности, подписи и значения экранируются.

Пилот: форма «Связать задачу» в метриках. Локальный поиск из metrics.js заменён
контроллером. При смене типа очищается прежний ID, при закрытии запрос отменяется.
Существующие проверки прав, черновика и серверная валидация сохранены. API,
модель данных и БД не менялись. Каталог содержит работающий пример.

Данные текущей выдачи не определяют действительность выбранной записи: при
уточнении поиска выбор сохраняется; явно disabled-запись очищается. Сервер
проверяет доступ и допустимость связи при сохранении. Enter в поиске запускает
поиск без отправки формы, а после ошибки повтор возвращает фокус к поиску.

## Проверки

- **17/17 браузерных сценариев PASS**, exit code 0: 13 сценариев компонента
  и каталога, 4 интеграционных сценария метрик. Light/dark, 320/390/1440 px,
  длинные названия, экранирование, клавиатура, required и FormData; задержанные
  ответы, AbortSignal, error/retry, сохранение выбора, сброс контекста, reset
  формы, disabled, повторная привязка и destroy. Enter не отправляет форму.
- В метриках проверены смена типа, конкретный target_id в запросе, ошибка 422
  у поля с сохранением выбора, подтверждение закрытия и отмена незавершённого
  поиска. Предыдущие сценарии карточек/измерений также проходят.
- **34/34 Node-проверки PASS**: renderer, UI API, токены, границы core,
  доступность диалогов и обнаружение потребителей.
- Инвентаризации семейств/потребителей пересобраны, обе проверки `--check` PASS.
  Общий `check-review-coverage.mjs` остаётся **FAIL** на прежней устаревшей
  записи `avatar → js/app.js`. EntityPicker зарегистрирован как pending;
  полная живая приёмка и исправление чужих доказательств не заявлены.
- Финальные снимки просмотрены: форма метрик на 390 px и длинный выбор на
  320 px в тёмной теме. Артефакты: `dmb-backlog/.runtime-ui-picker-final/`,
  не предназначены для Git.

Повторить: `npm run test:ui-picker` из `dmb-backlog/`. Собственный статический
сервер 4189; ответы API и ошибки сохранения задаются фикстурами, реальные запросы
на изменение данных не отправляются. Это компонентная и интеграционная проверка,
не полная живая ролевая приёмка и не общий `verify:ui-kit`.

## Границы

Реализован одиночный выбор. Не включены множественный выбор, создание сущности
из поля, пагинация и виртуализация. Остальные предметные поисковые поля пока
не перенесены. DateRange/NumberRange, StepForm и SplitPane остаются далее в плане.
