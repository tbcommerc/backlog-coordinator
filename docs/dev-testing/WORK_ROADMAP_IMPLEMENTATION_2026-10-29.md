# Рабочие задачи: реализация и проверка 29.10.2026

Основание — [план W01–W72](../WORK_TASKS_VISION_AND_ROADMAP_2026-10-29.md).
Этот отчёт фиксирует первую поставку. Весь план, этап S1 и полная приёмка
продукта не объявляются завершёнными.

## Внесённые изменения

| Пункты | Реализация | Оставшиеся границы |
|---|---|---|
| W02 | Последние комментарии при открытии; курсор `before`, `limit`, `paginated`; загрузка предыдущих комментариев и ранней истории; сохранение режима активности | Длительное чтение при одновременных событиях и сетевых отказах требует отдельного прогона |
| W03 | Переход `cancelled → new` с причиной, правом редактора команды, optimistic version, историей и повторным разбором назначения | Восстановление не означает автоматическое подтверждение прежней готовности |
| W04, W47 | Причина изменения ожидания/приёмщика после старта; прежние значения в истории; предъявленный результат возвращается в работу без потери текста; ревизия результата меняется | Отдельное согласование изменений всеми участниками, сравнение редакций рядом и расширенный сценарий замещения не реализованы |
| W09 | Серверный поиск Task, WorkTask, проектов и доступных запросов; тип, публичный ID, ACL и серверные страницы; точное совпадение ID первым; шапка открывает соответствующий объект | В шапке показаны первые результаты и предложение уточнить запрос; отдельного полного экрана поиска/контекста результата пока нет |
| W10 | Поиск WorkTask по описанию и фактическому результату во всех общих выборках | Дополнительные интервалы дат, автор и приёмщик как фильтры не добавлены |
| W59 | При открытом инспекторе условия свёрнуты, явная кнопка возвращает их без сброса | Требуется последующая проверка всех комбинаций содержимого |
| W60 | Полный экран, возврат в инспектор, предыдущая/следующая задача текущей страницы; регулировка ширины 440–760 px с сохранением для пользователя в браузере и ограничением доступной шириной | Межстраничная навигация не добавлена; граница текущей страницы объясняется явно |
| W01, W64, W71 | Единые переходы карточки/доски; исправлена обработка неверных фильтров доски как HTTP 422; добавлена сценарная регрессия | Это адресное покрытие, не полная межролевая приёмка |

API и правила описаны в [профиле рабочих задач](../../dmb-backlog/docs/WORK_TASKS.md).
Миграций и новых переменных окружения в этой поставке нет.

## Проверки

- Серверная регрессия `backend/work_tests`: **84 PASS**, включая ACL запросов,
  курсоры и причины изменения условий.
- Существующие браузерные проверки карточки, инспектора и панели условий:
  **43 PASS**. Они включают обе темы, 320/390/768/1024/1440 px,
  черновики, комментарии, вложения, исполнение и приёмку.
- Последующий расширенный прогон: **52 PASS / 1 FAIL**. Проверка максимальной
  ширины модальной карточки ожидала 600 px, после параллельного внедрения
  общего DetailPanel получила 768 px. Этот результат не скрыт успешным ранним
  прогоном. Другой чат продолжает менять карточку и UI kit; пользователь
  подтвердил это в текущем чате. Финальная интеграционная приёмка ожидает
  стабилизации общего дерева.
- Общий frontend unit-прогон после адресных исправлений контрактов:
  **445 PASS / 2 FAIL**. Незакрыты регистрация новых экспортов Detail-компонентов
  и инвентаризация диалога сопровождения запроса. Последний диалог после прогона
  зарегистрирован как `pending`; успешная визуальная приёмка ему не присвоена.
- Новые браузерные сценарии: все 250 комментариев и 150 событий доступны;
  восстановление требует причины; полный экран и переход по очереди работают;
  верх инспектора на 1422 × 800 находится не ниже 200 px.
- Живой вход под готовым QA-профилем участника; поиск WRK-27 из шапки
  другой страницы, переход в карточку и чтение без изменения рабочих данных.
- Живой viewport 1422 × 800: верх инспектора **163.44 px**, высота **624.56 px**,
  ширина **559.99 px**. [Снимок](evidence/work-roadmap-2026-10-29/live-inspector.png).
- Штатный запуск завершился успешным health-check backend, AI-агента и Agent V2;
  PostgreSQL/Redis healthy. Task Prioritiser выключен.

При расширении unit-прогона найдены рассогласования контрактов UI kit: публичные
экспорты фильтров не входили в реестр семейств, предметные селекторы фильтров
попали в core, два предметных helper-модуля отсутствовали в матрице, фильтры
подключались динамически в обход discovery, высота кнопок метрик задавалась
страницей. Реестры согласованы с кодом, предметный CSS перенесён в адаптеры,
геометрия — в sizing, импорт сделан статическим. Статусы визуальной приёмки
от этого не повышаются.

Новые серверные тесты используют изолированные рабочие таблицы без записей
пользователей, команд, ролей и справочников. SQLite используется только как
изолированный тестовый движок, приложение продолжает работать на PostgreSQL.

## Незавершённая область плана

W05–W08 требуют общей проекции ожиданий, семантики KPI, расширенной проверки
сохранности и отдельного архива. W11–W28: представления, быстрые/массовые операции,
личное планирование, напоминания и повторения. W29–W58: командный поток,
обсуждения, связи, встречи, интеграции и автоматизация; адресные изменения
W47 не закрывают весь сценарий. W61–W72: полный контракт поверхностей,
доступность, реальный touch/zoom/screen reader, нагрузка, наблюдаемость,
восстановление, пилот и измерение удобства остаются открытыми.

Ни один успешный автоматический прогон не заменяет эти критерии.
