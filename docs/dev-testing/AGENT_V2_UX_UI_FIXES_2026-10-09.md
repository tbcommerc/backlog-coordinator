## Повторная диагностика AI

На настроенном OpenCode Go / `glm-5.3-flash` выполнен сценарий с искусственным
материалом, без SessionStore и обращений к рабочей БД. Генерация работала;
ревью дважды завершалось в degraded. Во втором прогоне установлена точная
причина: `unsupported_related_quote` для точной цитаты «Средний» из имеющегося
поля `priority`. Валидатор ошибочно требовал, чтобы связанное поле было ещё
и редактируемым.

Добавлен отдельный список полей, допустимых для ревью, и он передаётся модели.
Разрешение цитировать поле не даёт права его изменить; проверка буквального
совпадения сохранена. Регрессии подтверждают допустимость существующей цитаты,
отказ от выдуманной цитаты и запрет изменения приоритета через предложения.
Для таких замечаний скрывается неприменимая кнопка AI-правки.

После исправления реальный прогон завершился успешно: **8 предложений**,
затем их применение в памяти и **12 замечаний** с `review.status=completed`.
До принятия предложений документа не было; ревью не изменило принятую редакцию.
Это подтверждает работоспособность контракта на одном синтетическом примере,
а не качество модели на материалах заказчика. Исходная причина каждого сбоя
исторического аудита отдельно не восстановлена.

## Проверки и ограничения

- Полный изолированный набор Agent V2: **402 passed** (17 предупреждений библиотек).
- Frontend: **18 модульных проверок**.
- Playwright: **18 passed**; HTTP-ответы подменены.
- Размеры: 1920×1080, 1440×900, 1366×768, 768×1024, 390×844, 320×740.
  Desktop fixture учитывает 240 px глобальной навигации. Проверены достижимость
  инструментов и начало содержимого на первом экране, а не только overflow.
- Снимки: [папка результатов](../../outputs/agent-v2-ux-fixes-2026-10-09/).
- Несохранённые формы существуют только в памяти вкладки, без записи в localStorage;
  аварийное закрытие/подтверждённая перезагрузка их не восстанавливают.
- Рабочие и защищённые записи БД не менялись. Человеческое согласование, уведомления
  и создание задач на живом стенде не выполнялись. Screen reader и другие браузеры
  не проверялись; клавиатурная и ARIA-проверка не является полной сертификацией доступности.
- После подтверждения пользователя 09.10.2026 Agent V2 точечно перезапущен.
  `/api/agent-v2/ready` вернул `ready`: БД доступна, LLM настроена, feature включён.
  Обновлённая страница `#/agent-v2` открыта в браузере и проверена визуально по UI.

Команды повторения описаны в [TESTING](../../agents/business-analyst-experimental/docs/TESTING.md).
