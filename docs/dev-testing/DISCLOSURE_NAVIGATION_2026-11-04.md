# Нейтральная навигация и текстовое раскрытие

Проверено 04.11.2026. Реализация выполнена; проверка — fixture.
Live-приёмка всех экранов не заявляется. Защищённые данные БД не изменялись.

## Решение

Сохранены композиции реестров, карточек и реестра с инспектором.
Основной сценарий проектов — выбрать период и увидеть план/Гант на первом экране.
Ссылки со стрелками в проектах и меню уведомлений заменены именованным вариантом
UI Kit `ui-nav-action`: нейтральная кнопка со штатным href.
Ссылки на сущности внутри данных сохраняют обычное оформление.

`ui-disclosure-text` добавлен к summary в активных JS-потребителях и общих
collapseSection/sectionCard. Маркер заменён текстом «Показать / Скрыть» справа.
Сохранены details/open, Enter/Space и обработчики. Группы рабочих задач используют
текст вместо ▸/▾ и сохраняют aria-expanded. Локальные акцентные переопределения
раскрытия проектов удалены. Новые стили принадлежат UI Kit.
Меню действий метрики и сложная карточка замечания агента сохраняют специальные
контролы; сортировка и стрелки истории не входят в область задачи.

## Функциональность

- Исходный projectVisualAcceptance: 6 PASS, 320/390/1440, обе темы.
- disclosureNavigation: 4 PASS, обе темы, 390/1440, Enter/Space,
  отсутствие горизонтального переполнения, переход в предыдущий квартал.
- metricsQuarterly, workTaskDrawer, uiKitDetailComponents, agentChatResponsive:
  98 PASS.
- uiPageCompositionVariants: 2 unit-теста PASS.
- Пилот рабочих задач в режиме сохранения снимков: 10 PASS.
  Этот режим проверяет поведение и сохраняет экраны, но не сравнивает с эталонами.
- Обычный `npm run test:design`: 3 PASS, 7 FAIL по сравнению снимков.
  Расхождения также затрагивают типографику/геометрию реестра без раскрытия.
  Эталоны не обновлены, screenshot-регрессия остаётся открытой.
- Общий test:unit не зелёный: среди ошибок несовпадение версии UI Kit 34/33
  и EPERM записи отчёта производительности. Полный unit PASS не заявляется.

## Визуальная оценка и UI Kit

Осмотрены исходные и итоговые полные экраны проектов на 1440/390 px, включая
раскрытые фильтры; экраны рабочих задач/инспектора и мобильной карточки,
каталог композиций, мобильная форма квартальных планов.
На осмотренных экранах треугольники секций заменены текстом, навигация периода
имеет нейтральный вес; подписи помещаются. Раскрытые мобильные фильтры увеличивают
высоту страницы, но не создают горизонтального переполнения.

Impeccable detect нового CSS: замечаний нет. Это механическая проверка,
не визуальная приёмка. Полное визуальное покрытие всех потребителей,
живой БД и ролей остаётся открытым.
