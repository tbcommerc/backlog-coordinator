повторный полный снимок подтверждает читаемые значения и доступ к остальным
колонкам через горизонтальную прокрутку.
Финальный design-прогон после исправления мобильной таблицы: 32 PASS, 5 FAIL
(`dmb-backlog/artifacts/task-card-design-final.txt`).
`npm run test:design` выполнен на Windows Chromium. Пять прежних расхождений
workDesignPilot не скрыты обновлением эталонов. Контроль с подменой только наших
изменённых файлов их HEAD-версией показал побайтово одинаковые screenshots
реестра light 1440, dark 1366 и редактора рабочей задачи:
[сравнение](../../artifacts/task-card-remediation-2026-11-09/baseline-comparison.json).

Каталог модалок отличается в статическом образце карточки вследствие удаления
широкого reset. Общая геометрия header/body/footer проверена; старый каталог
не является эталоном новой композиции карточки. Скриншот не обновлялся ради PASS.

`verify:ui-kit` запускался и остановился на глобальном unit-наборе: 14 ошибок,
включая устаревшие ownership/token/inventory-контракты и недоступный performance
артефакт. `check:ui-review` и `check:ui-acceptance` фиксируют изменившееся discovery
(в том числе новый потребитель ReadOnlyField). Глобальные gates не ослаблены,
receipt полной приёмки не выдаётся.

Функционально подтверждены перечисленные пути. Визуально новая сводка читается
на первом экране; устранены повтор названия, оттеснение исполнения описанием,
избыточные внутренние рамки, сжатие ID мобильного редактора и перекрытие действий
сообщением. UI Kit: существующие общие компоненты и варианты, без новой палитры
и повышения CSS-специфичности. Полная визуальная/AT/live-приёмка всей матрицы
остаётся открытой в явно перечисленных строках.
