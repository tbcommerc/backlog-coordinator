# DateRange и NumberRange в UI Kit

Дата проверки: 29.10.2026. Четвёртая очередь дополнений после сравнения с IBP.

## Реализация

- `dateRange` и `numberRange`: fieldset/legend и два Field на нативных input.
  Общие токены, подписи, hint, required/disabled/readonly, min/max/step,
  адаптивное расположение границ до 420 px. Пользовательские строки экранируются.
- `validateRanges` возвращает ошибки конечных полей для существующего
  `showFormErrors`. Значения не переставляются и не исправляются автоматически.
  Ноль, равные границы, отрицательные/дробные значения и одна необязательная
  заполненная граница поддерживаются. Native validation остаётся у браузера.
- Форма периода метрики использует оба компонента. Порядок числовых границ
  проверяется только для направления range; проверка даты первого замера
  остаётся предметной. Ошибки не отправляют запрос и не стирают значения.
- Примеры в каталоге интерактивны; семейство Intervals зарегистрировано
  в инвентаризациях. API, модель данных и серверные правила не изменялись.

## Проверки

- **14/14 браузерных сценариев PASS**, exit code 0: 10 проверок диапазонов и
  каталога, 4 интеграционных сценария метрик. Light/dark, 320/390/1440 px;
  ошибки порядка, равные границы, ноль, дроби/экспонента, необязательные границы,
  нативные ограничения, required, readonly/disabled/hidden, reset и FormData.
- В метриках проверены отсутствие запросов при неверных границах, отдельная
  проверка даты первого замера, передача нулей и дат в API-фикстуру, сохранение
  значений при ошибке сервера и отключение сравнения чисел при направлении up.
- Финальные снимки ошибок в тёмной теме на 320 px и формы метрик на 390 px
  просмотрены. Артефакты: `dmb-backlog/.runtime-ui-intervals-final/`, не для Git.

- **34/34 Node-проверки PASS**: API компонентов, безопасная разметка, токены,
  границы core, доступность диалогов и обнаружение потребителей.
- Обе проверки инвентаризаций `--check` PASS. Общий контроль покрытия ревью
  остаётся **FAIL** на прежней записи `avatar → js/app.js`. Семейство Intervals
  зарегистрировано как pending; прежние доказательства сохранены.

Повторить: `npm run test:ui-intervals` из `dmb-backlog/`. Сервер 4190,
изолированные API-фикстуры, без изменений реальной БД и защищённых данных.
Это компонентная/интеграционная проверка, не полный `verify:ui-kit` и не
живая ролевая приёмка всех форм приложения.
