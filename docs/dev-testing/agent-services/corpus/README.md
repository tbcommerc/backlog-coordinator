# Синтетический корпус миграции

Зафиксирован 03.11.2026, версия 1.0.0. [Manifest](v1/manifest.json) содержит SHA256
пяти файлов: по 12 сценариев, всего 60. В каждом определены вход, обязательные
факты, запрещённые выводы/эффекты и assertions. Первые четыре на сервис выбраны
для live: обычный путь, уточнение/пустой результат, корректировка/повтор и защита.
Справочники в испытаниях допускаются только как in-memory mocks.

Проверка целостности и шаблон отчёта:

```powershell
.venv/Scripts/python.exe scripts/check-agent-corpus.py --report-template .runtime/agent-services-evidence/corpus-planned.json
```

Проверка hashes/schema не является продуктовым replay и не отмечает 60 случаев
PASS. Шаблон содержит отдельные baseline/candidate и все assertions NOT_RUN.
Существующий файл evidence не перезаписывается. Корпус подготовлен после первых
транспортных изменений; прежний baseline задним числом не заявляется.
Для сравнения нужны реальные артефакты обеих версий, одинаковые модельные
профили и ограниченный live budget. Старые transport-only smoke не заменяют
продуктовый baseline этого корпуса. Изменение входа или oracle требует новой
версии и явного пересмотра сравнения.
