## Контракт и границы

Фильтры применяются **до пагинации**, только к доступным пользователю задачам.
Команда каталога относится к задачам бэклога, а не к изменению состава команд.
Сигналы каталога явно подписаны как данные бэклога; они не выдают рабочие задачи
или метрики за общий процент завершения проекта. Показатели текущие, не исторический срез.

В результатах четыре независимых чтения API получают точные счётчики, затем
отображается выбранный вид. Редактирование защищённых сущностей не добавлено.
