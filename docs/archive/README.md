## Границы уборки

Удалены шесть производных файлов текущего графа (graph.json, graph.html, GRAPH_REPORT.md, .graphify_labels.json, .vocab.txt, manifest.json) и пять старых .pyc-кэшей (всего около 21 МиБ). Сохранены исторические снимки графа, memory/reflections, вспомогательные скрипты и сведения о стоимости построения. Для актуального графа требуется новый build.

БД, резервные копии, выгрузки, виртуальные окружения, .runtime, тестовые данные в .tmp/.tmp_pytest/.test-tmp-agent и каталог %SystemDrive% сохранены. В последних есть БД и полезные материалы; целиком считать их мусором нельзя. Рабочий код, CI и незакоммиченные реализации не изменялись.

Файл agent/agent/prompts/system_prompt.md сохранён как исторический материал: основной runtime использует SYSTEM в dialogue/agentic.py. Изменение Markdown-файла не меняет основной prompt; его архивирование нельзя смешивать с этой уборкой без проверки всех потребителей.
