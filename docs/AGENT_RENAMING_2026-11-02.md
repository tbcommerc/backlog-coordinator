# Переименование агентов — 02.11.2026

Пользователь выбрал названия по роли, с явным обозначением экспериментального бизнес-аналитика. Изменения выполнены локально без staging, коммита и отправки в GitHub.

## Новая структура

| Прежний каталог | Новый каталог | Основной Python-пакет |
|---|---|---|
| `agent/` | [agents/business-analyst](../agents/business-analyst/README.md) | `business_analyst` |
| `agent-v2/` | [agents/business-analyst-experimental](../agents/business-analyst-experimental/README.md) | `business_analyst_experimental` |

| `prioritiser-agent/` | [agents/value-priority-assessor](../agents/value-priority-assessor/README.md) | `value_priority_assessor` (прежде `app`) |

Разбор расшифровок использует [business_analyst/meeting_task_extractor.py](../agents/business-analyst/business_analyst/meeting_task_extractor.py), прежде `agent/agent/meeting_extraction.py`. Это пятая продуктовая роль внутри общего сервиса бизнес-аналитика, а не отдельный процесс.

Экспериментальная точка входа `run_v2.py` переименована в `run.py`; проверка конфигурации запуска — в [test-business-analyst-experimental-llm-config.ps1](../scripts/test-business-analyst-experimental-llm-config.ps1).

## Что обновлено

- Абсолютные и относительные Python-импорты, ASGI/CLI entrypoints, пути к prompts и ресурсам, тесты и настройки pytest.
- [Штатный запуск](../scripts/start-project.ps1), [ассистент по бэклогу](../scripts/start-backlog-assistant.ps1), status/stop и проверка наследования настроек модели.
- Dockerfile, production Compose, пути CI, примеры команд, корневой README, навигация и относительные ссылки исторических документов. Содержание исторических результатов не объявляется перепроверенным.
- Editable-метаданные локального окружения ассистента, Windows console launchers и пути активации. Новые зависимости не скачивались. Попытка перестроить editable install штатным pip обнаружила отсутствие setuptools; вместо установки дополнительных пакетов исправлены существующие локальные метаданные.
- Локальные пути конфигурации и сертификатов без вывода секретов. Git и Docker исключают вложенные окружения, временные каталоги и секреты.
- Зависимые каталоги UI и документ матрицы пересобраны после изменения путей.

## Совместимость

API, URL страниц, имена рабочих БД, переменные окружения `AGENT_*`, `AGENT_V2_*`, `PRIORITISER_*`, идентификаторы Docker-сервисов и PID/логов сохранены. Это протоколы и локальные идентификаторы совместимости, а не прежнее расположение исходников.

Канонические флаги: `-IncludeValuePriorityAssessor` и `-IncludeBusinessAnalystExperimental`. Старые `-IncludePrioritiser` и `-IncludeAgentV2` работают как PowerShell aliases с прежней семантикой. Экспериментальный бизнес-аналитик входит в обычный запуск; оценщик требует отдельного явного включения.

Существующие корневые окружения `.venv`, `.venv-agent-v2`, `.venv-prioritiser` не перемещались. Окружение ассистента перенесено вместе с ним и исправлено для нового пути.

Полный прогон оценщика был начат, затем остановлен после обнаружения фикстур, заполняющих временные справочники. Часть таких тестов успела выполниться только в индивидуальных SQLite-каталогах `.runtime/rename-assessor-*`; рабочая БД оценщика этим прогоном не использовалась. Эти фикстуры запрещены правилами проекта даже для тестирования, поэтому окончательный прогон ограничен перечисленными безопасными проверками. Полная регрессия финансовой методики этой задачей не заявляется.

Три исходных frontend-сбоя: `U28 core boundary follows every transitive CSS import`, `page CSS cannot set vertical dimensions on shared buttons and fields`, `active styles and templates cannot reintroduce tiny text or private weights`. Они воспроизводились до переименования; CSS рабочего места этой задачей не исправлялся.
