## Изменения

Именованная композиция UI Kit `ui-task-secondary` вынесена в
`dmb-backlog/frontend/css/ui/task-secondary-composition.css`, подключена через
`kit.css`. Она использует общие цветовые токены, Button, Badge, Avatar, Control,
DescriptionList, SectionCard plain. Размер mobile history meta поднят до 12 px
по действующему контракту UI Kit. Legacy shell adapters исправлены root отдельно.

- Отчёты: блок на всю ширину, две смысловые колонки, компактные пустые встречи,
  явное открытие редактора, отдельные отмена/сохранение. Сохранены версии,
  черновики других встреч, ошибки, повтор и доступность только по can_edit.
- Комментарии: обычная лента с разделителями, вложенные ответы, единый composer;
  счётчик включает ответы. Сохранены mentions, черновики, отправка и маршруты.
- Ссылки и файлы: материалы → список файлов → drop zone → системное disclosure.
  Сохранены безопасные URL, скачивание, удаление, один file picker и API.
- История: лента с временем, аватаром, автором, полем и значениями до/после;
  справочные значения разрешаются через справочники. Ноль не заменяется пустотой.
- Рабочие задачи: отдельный режим `composition: task-detail` существующего
  mountWorkList/mountRelations. Один поиск, список вместо таблицы/KPI, статус,
  исполнитель, срок, привязка/создание, внешние связи. Другие экраны сохраняют
  общий renderer. Кнопка «Зависимости» открывает существующую рабочую карточку.

Backend PATCH ранее терял ноль в TaskHistory через truthiness. Две строки
заменены на `is not None`; новые 0→47,47→0,null→0,0→null сохраняются корректно.
Исторические null не переписаны: исходное значение восстановить достоверно нельзя.

## Визуальная оценка

Свежие 30 полных fixture-снимков: `dmb-backlog/artifacts/task-card-secondary-2026-11-11/`
(5 вкладок × 1440/390/320 × light/dark). Парные снимки source/actual:
`dmb-backlog/artifacts/task-card-secondary-reference-2026-11-11/` (20 PNG,
1440×960 и 390×844, плюс geometry JSON). Ошибки/повтор/busy/conflict/AI/zero:
`dmb-backlog/artifacts/task-card-states-2026-11-11/`.

Осмотрены полные desktop5, мобильные comments/history и dark узкие files/report;
пары source/actual files/comments/work сверены визуально и геометрически.
Композиция соответствует референсной последовательности и плотности;
таблицы истории/рабочих задач, карточки комментариев и трёхколоночные отчёты
заменены. Лишние отступы материалов убраны, рамки secondary-кнопок видимы.

Границы визуального совпадения:

- Work row 109 px против 107 px source; до исправления inline ID было112.
  Внешнее исполнение начинается на первом экране, как в source. Native status
  select и общие кнопки сохранены, фиктивный prototype filter не внедрялся.
- Comments: реальное дерево root+reply236 px и root118 px против трёх плоских
  source строк по115 px; разница9 px. Вложенность сохраняет бизнес-смысл.
- В fixture две Jira URL вместо одной source: дополнительные27 px обоснованы
  данными. URL не заменены вымышленными подписями, API метаданных названия нет.
- API даёт три типа встреч, prototype показывает четыре. Production не
  дополняется вымышленной четвёртой встречей или статичными названиями статусов.
- Верхняя proof-bar source занимает44 px и отсутствует в приложении; позиция
  всей оболочки отличается на22 px по вертикали. Это окружение, не body padding.
- На узких экранах длинное содержимое прокручивается внутри тела. Никакого
  горизонтального переполнения на 320/390/1440 в проверенных вкладках нет.

Live-обход ведёт root отдельно; fixture не выдается за live. Все состояния
свободного содержимого, всех ролей и assistive technologies этим набором не
исчерпаны. Общий test:design, весь unit suite и live итог агрегирует root.

Активный профильный документ обновлён: `dmb-backlog/docs/TASK_CARD.md`.
